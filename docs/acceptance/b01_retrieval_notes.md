任务分支：feat/b01-topic-retrieval。

## 修改理由与前后结果

长问题中的“思想政治教育”和“政治教育”匹配全部245条语料，
轻量召回同分截取导致具体事件材料被排除。修复前，遵义会议问题
前三条为001、021、028，新增主题回归失败。

现在优先使用能区分语料的实体，并在生成前筛除只匹配通用实体的
融合证据；只有通用实体的问题保留原召回。对外query_entities、
原始图谱召回与GraphSim报告保持不变，未修改语料、页码或接口。

修复后目标问题前三条为111、112、117，引用为111、117。
新增短问题及泛化问题回归，后端106项测试通过。
“长征形成了什么精神？”能够返回相关材料，但当前摘要未完整展开
精神内涵，保留为待验收项，不能仅凭approved判定教学内容正确。

## 三类响应与复现

完整样例：[retrieve_responses.json](../../tests/fixtures/competition/retrieve_responses.json)。
保留请求、完整响应、生成时间、源代码提交和运行方式。

| 状态 | 请求 | 自然触发条件 |
|---|---|---|
| approved | 遵义会议后的思想政治教育有哪些作用？ | 有可引用证据，现有规则检查通过 |
| needs_review | 抗日战争时期党的干部教育为什么重要？ | 历史语境关键词触发人工复核，can_output=false |
| blocked | 量子芯片如何纠错？ | 无可用证据，can_output=false，无引用 |

待复核问题属于主题外的回归案例，用于验证前端状态展示。
响应由FastAPI TestClient调用真实/retrieve后端产生，无响应注入。
它是进程内ASGI调用，不等同于浏览器或网络端到端验收。

在项目根目录执行（使用已配置的cmit_2026环境）：

```powershell
python -B scripts/export_competition_response_fixtures.py
python -B -m pytest tests -q -p no:cacheprovider
```

导出脚本固定本地mock检索、确认标记与template生成，移除本进程的
向量后端覆盖配置，不调用在线模型。已有样例时拒绝覆盖；重新生成
应先保留历史文件，再明确安排新输出。前端读取samples中的response，
不把带metadata的整个文件当成单次接口响应。

## 限制与下一步

- 规则通过不代表历史结论已获专家确认或教学效果已验证。
- F01使用这三类响应联调证据原文与门控；D01继续资料及题单复核。

# 智证思政三人开发任务看板

作品：智证思政——基于知识图谱与证据审查的可信AI交互式教育系统。
主题：从遵义会议到长征精神：沿着证据理解历史。
初始化基线：main@451fab9。
当前代码交接基线：main@59149b2（PR #2、PR #4已合并）。
仓库：https://github.com/upstream1119/zhizheng-sizheng-cmit-2026
运行指南：https://github.com/upstream1119/zhizheng-sizheng-cmit-2026/blob/main/docs/competition_bootstrap.md

## 一、目标、分工与顺序

报名版完成一个可连续演示的教学单元：
提问 → 阅读回答 → 打开证据原文 → 探索关系 →
查看地图时间轴 → 根据材料完成一道综合解释题。
至少完成一个图谱场景、3—5个有依据的事件及10道端到端验收。

彭意涵负责后端、接口契约、证据质量、审核门控和整体验收。
严欣浩负责前端问答、证据阅读、图谱及地图时间轴。
徐若诚负责运行交付、事件资料复核、验收题单和录制组织。

第一批B01、F01、D01可并行准备。
F01最终联调依赖B01响应样例；地图时间轴开发依赖D01复核资料。
建议10月10日前完成首批PR或资料初稿，10月13日前完成核心联调。
日期是团队目标；遇到阻塞及时记录原因及影响，不虚报完成。

## 六、进度与交接规则

云盘看板负责日常状态；GitHub负责代码与验收证据。
状态使用：未开始、进行中、待联调、待验收、完成、阻塞。
勾选完成必须附PR、测试日志或正式交付链接。
PR写明任务编号、改动文件、验证命令、结果及限制，由另一人复核。
禁止直接在main开发、强制推送或覆盖他人未提交内容。
反馈模板：任务编号｜分支｜当前提交｜已完成｜证据链接｜
未完成｜阻塞原因｜需要谁配合。

后续顺序：主题问答与证据阅读 → 图谱关系探索 →
地图时间轴 → 在线模型与整体验收 → 冻结、录制、材料提交。
